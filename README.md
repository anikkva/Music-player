# Автомагнитола — 3D-плеер

Музыкальный плеер, у которого нет интерфейса: вместо панели с кнопками —
автомагнитола в салоне машины, на которую смотришь от первого лица. Мышью
поворачиваешь голову и приближаешь кадр, кликаешь по физическому органу
управления — в кадр входит рука, дотягивается и нажимает, и только в момент
касания срабатывает действие.

Визуальный ориентир — кадры из GTA III (см. `docs/reference/`).

## Запуск

```bash
python3 serve.py 4181
```

Дальше открыть <http://localhost:4181>. Нужен любой статик-сервер: проект — это
ES-модули без сборщика, Three.js подключается с CDN. `serve.py` отличается от
`python3 -m http.server` только тем, что отключает кеш, чтобы правки были видны
сразу после перезагрузки.

В магнитоле играет **живое интернет-радио**, а не файлы: семь станций
захардкожены в `src/stations.js`, все потоки — по HTTPS (браузер блокирует
plain-HTTP медиа на HTTPS-странице). Ничего не играет само и ничего не
загружается по сети, пока не нажата **VOL**.

Файлы в `assets/audio` остались от ранней разработки и в собранный сайт не
попадают — см. `netlify-build.sh`.

## Управление

| Орган | Действие |
|---|---|
| ◀ SEEK ▶ (обе пары) | предыдущая / следующая станция |
| VOL (крутилка слева) | play / pause |
| TUNE (крутилка справа) | громкость: drag по кругу или колесо мыши над крутилкой |
| AM, FM, BAND, EJECT, щель кассеты | декоративные: нажимаются, действия нет |
| drag по пустому месту | повернуть голову |
| колесо мыши | зум |

Маппинг сознательно не совпадает с реальной автомагнитолой — так задумано в спеке.

## Тесты

```bash
npm test
```

Покрыта только чистая логика без DOM, WebGL и audio API: переход по станциям,
перевод угла крутилки в громкость, ограничения камеры и бегущая строка дисплея.
3D-взаимодействие проверяется вручную в браузере.

## Структура

```
index.html            — canvas и стартовый оверлей
styles/style.css      — оверлей, курсоры, подсказки
src/
  main.js             — сборка сцены и связывание контролов с плеером
  stations.js         — станции (name, genre, url, mood)
  playlist.js         — переход по индексу станции (чистая логика)
  player.js           — HTML5 Audio: эфир, станции, громкость, обрывы потока
  knob.js             — угол крутилки ↔ громкость (чистая логика)
  cameraMath.js       — ограничения yaw/pitch/zoom (чистая логика)
  marquee.js          — бегущая строка дисплея (чистая логика)
  camera.js           — first-person камера с инерцией
  layout.js           — где стоит магнитола (общее для радио и торпедо)
  textures.js         — процедурные текстуры и фолбэки
  scene.js            — рендерер, свет, панорама за стеклом
  interior.js         — салон: торпедо, консоль, руль, стекло, зеркало
  passenger.js        — пассажирка на переднем сиденье и колени водителя
  radio.js            — 3D-модель магнитолы и её органы управления
  lcd.js              — живая CanvasTexture дисплея
  hand.js             — низкополигональная рука и её анимации
  interaction.js      — raycasting: hover, клик, drag крутилок
assets/audio/         — треки
docs/superpowers/     — спека и план реализации
docs/reference/       — референсные кадры
```

## Деплой

Netlify собирает сайт сам: `netlify.toml` запускает `netlify-build.sh`, который
складывает в `dist/` только `index.html`, `styles/` и `src/`. Ни треков, ни
спек, ни тестов на публичном URL не оказывается.

Локально ту же сборку можно проверить так:

```bash
sh netlify-build.sh
```

## Отклонения от спеки фазы 1

- **Салон — 3D-геометрия, а не только панорама.** Спека предполагала панораму на
  внутренней стороне сферы. Панорама осталась, но она показывает только то, что
  видно через стёкла: чтобы магнитола стояла в настоящей приборной панели и
  совпадала с ней под любым углом, сам салон смоделирован. Персонажи фазы 2
  живут в этой же геометрии.
- **Пассажирка на переднем сиденье появилась уже сейчас** — по прямой просьбе.
  Формально это контент фазы 2; поле `mood` по-прежнему ни на что не влияет.
- **Вместо шести mp3 — живое радио.** Спека фазы 1 описывала плейлист из
  файлов. Файлы остались бы публично раздаваемой чужой музыкой, поэтому плеер
  переведён на потоки радиостанций: по концепции это даже точнее — SEEK теперь
  делает ровно то, что делает на настоящей магнитоле.

## Фаза 2

У каждого трека уже есть поле `mood` (`romantic | energetic | kids | neutral`),
но в фазе 1 оно ни на что не влияет — у всех треков `neutral`. Смена окружения
салона по настроению трека проектируется отдельной спекой.
